# Font quân cờ

`XiangqiBrush-Regular.ttf` là bản rút gọn từ
[LXGW WenKai TC Medium](https://github.com/lxgw/LxgwWenkaiTC), chỉ giữ các
ký tự xuất hiện trên bàn cờ (tên quân, chữ ở sông và số cột). Font gốc được
phát hành theo SIL Open Font License 1.1; giấy phép đi kèm ở [OFL.txt](OFL.txt).

Nguồn bản gốc:
`https://github.com/lxgw/LxgwWenkaiTC/blob/main/fonts/TTF/LXGWWenKaiTC-Medium.ttf`

Tập ký tự: `帥將仕士相象車馬砲炮兵卒楚河漢界123456789 `.

Font được rút bằng `font-subset` trong Flutter SDK. Chỉ dùng font này cho
chữ trên bàn cờ; nội dung giao diện vẫn dùng font mặc định của ứng dụng.
